# LAUNCH-17 — Accueil minimal et tutoriel permanent

Branche : `codex/launcher-minimal-posts`.

Conserver les trois flux aux positions validées, retirer leurs cadres, titres
de rubrique et actions permanentes. Montrer les publications individuellement
avec le visage du skin Minecraft de chaque auteur et le titre. Comme sur le
site, un clic déplie le texte complet et les images de la Gazette ; le flux
peut défiler sans déplacer le footer. Photos privées chargées à l’ouverture
avec la session Discord, sans cookie de navigateur ni jeton vers les avatars.

Conserver les cinq étapes dans Bien démarrer, premier onglet accessible après Discord,
dans la même fenêtre. Microsoft reste visible, avec son attente d'autorisation
expliquée ; aucun faux compte Microsoft et aucun lancement du jeu.
Les pages partagent une seule session et une seule installation officielle.
