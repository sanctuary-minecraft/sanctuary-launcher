# LAUNCH-02 — Accueil intégré et parcours local

Branche : `codex/launcher-local-onboarding`.

## Résultat vérifiable

Dans une seule fenêtre Sanctuary blanche, Accueil et Actualités précèdent les
journaux du jeu. L'accueil présente les cinq étapes tant que le parcours
n'est pas prêt, puis Jouer et les rubriques du site. Les outils natifs Prism
et les réglages globaux utilisent le même conteneur. Une seule instance
officielle est importée et synchronisée depuis la distribution Sanctuary Update.

## Recette

Voir la [recette datée](../implementation/launcher-local-20261108.md) : build,
24 suites, import réel, seconde synchronisation, navigation native et états
locaux. Le code SGA reste facultatif ; aucune simulation ne vaut admission.

## Hors livraison

Connexions Microsoft/Discord, admission réelle, activation du personnage,
jeu/serveur, validation Vulkan/audio et paquets distribuables restent ouverts.
Les contenus privés du site attendent leur pont de session authentifié.
