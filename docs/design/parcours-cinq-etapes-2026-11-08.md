# Déclinaisons du parcours en cinq étapes

Le 8 novembre 2026, Koka valide la composition Installation puis demande les
autres états sur la même base. Ces images statiques conservent un seul bloc,
le titre de l'étape active, le logo du site et Tous les outils Prism.

Les six déclinaisons ont été générées par Imagegen intégré à partir de la
composition validée et conservées sans retouche de pixels ni redimensionnement.
Les [consignes](blanc-cinq-etapes-2026-11-08/etapes/prompts.json) et
[empreintes](blanc-cinq-etapes-2026-11-08/etapes/provenance.json) sont conservées.
Leurs données sont fictives et ces nouvelles vues n'ont pas encore reçu de
validation distincte. Les glyphes sont un exemple visuel, pas un code encodé
valide. Le véritable parcours utilisera la police SGA et le code existant du joueur.

L'attente d'admission reste distincte de la capacité simultanée du serveur.
Afficher ou copier le code ne conditionne pas Jouer ; l'admission et une
installation vérifiée restent nécessaires. Ces images ne valident aucun
compte, jeu, serveur ou personnage réel.

Koka demande ensuite de passer au développement natif et d'arrêter la création
de maquettes. Le mode local doit être testable sans compte ; les essais réels
Microsoft, serveur et personnage sont différés à l'approbation Mojang.
